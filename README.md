# 💉 Gestão de Vacinas COVID-19

Este repositório contém a implementação de um sistema em **Python** voltado para a gestão e controle de dados relacionados às vacinas da COVID-19. O projeto foi desenvolvido como resolução do Problema 1 do módulo de Algoritmos.

## 🚀 Sobre o Projeto
O objetivo principal do algoritmo é aplicar os conceitos fundamentais de lógica de programação, estruturas de decisão e repetição para processar informações de forma eficiente e estruturada.

## 📂 Estrutura do Repositório
- `Problema 1 - MI Algoritmos.py`: Código fonte principal contendo toda a lógica do sistema implementada em Python.
- `Fluxograma.pdf`: Documento visual detalhando o fluxo de execução, as decisões lógicas e a arquitetura do algoritmo antes da codificação.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3.x
- **Conceitos:** Lógica de Programação, Estruturas de Dados Básicas, Algoritmos.

## 📖 Como Executar
1. Certifique-se de ter o Python instalado na sua máquina.
2. Clone este repositório ou baixe os arquivos.
3. Execute o script principal via terminal:
   ```bash
   python "Problema 1 - MI Algoritmos.py"
   ```
